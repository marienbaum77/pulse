# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability, please **do not open a public issue**.
Instead, open a [GitHub security advisory](https://github.com/marienbaum77/pulse/security/advisories/new)
or email the maintainer at [marienbaum77](https://github.com/marienbaum77).

We will respond within 48 hours and coordinate a fix.

## Supported versions

Only the latest release is supported. Keep your installation up to date by
pulling `main` or upgrading to the newest release.
